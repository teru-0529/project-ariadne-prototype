# 受注登録 API 詳細仕様

## 概要

受注情報と1件以上の受注明細を登録する。

対象API:

- `POST /orders`

## 前提

- 受注には1件以上の受注明細を含める。
- 受注番号は登録時に自動採番する。
- 受注日は登録時に自動設定する。

## 入力に関する補足

### 受注明細

`details` は必須とする。

- 最小件数: 1件
- 各明細には商品番号、受注数、販売単価を指定する。

## 処理概要

1. 受注情報を登録する。
2. 受注番号を採番する。
3. 受注明細を登録する。
4. 登録後の受注情報を返却する。

## エラーとなる例

- 受注明細が0件
- 指定された顧客IDが利用できない
- 商品番号が不正
- 入力値が各Elementの制約を満たさない
